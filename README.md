# AI Chatbot

A simple chatbot web app that lets users ask questions and get AI-generated answers in real time, powered by the Google Gemini API.

## What it does

- Takes a user's question as input
- Sends it to the Google Gemini API
- Returns and displays the AI-generated answer in a chat-style interface

## Tech Stack

- **Backend:** Node.js
- **AI:** Google Gemini API

## How it was built

This project was built with AI-assisted ("vibe-coded") development — I worked with an AI coding assistant to write and structure the app, which helped me learn how to wire up an API-driven chatbot end to end, from handling requests to displaying responses.

## Getting Started

```bash
# Clone the repo
git clone https://github.com/abigailnwizu-ux/ai-chatbot.git
cd ai-chatbot

# Install dependencies
npm install

# Add your Gemini API key to a .env file
GEMINI_API_KEY=your_api_key_here

# Run the app
npm start
```
